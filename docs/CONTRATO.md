## Comunicación
Nos comunicaremos a través de un grupo de WhatsApp exclusivo para la realización de este proyecto con todos los integrantes del Equipo1.
No debe pasar nunca un día sin responder, debiendo participar de forma activa.
Cuando un integrante enfrente un bloqueo deberá comunicarlo a través del grupo en un plazo máximo de 8 horas.

## Calidad

- Para que un Pull Request (PR) pueda ser fusionado (mergeado), debe cumplir estrictamente con el objetivo del issue para el que fue creado, además de mantener la integridad del código base y garantizar su correcto funcionamiento.
- La revisión de los PR se asignará mediante un sistema de rotación cíclica. Esto asegura que todos los miembros del equipo participen de forma equitativa en la revisión del código del resto de compañeros.
